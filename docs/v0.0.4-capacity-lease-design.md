# v0.0.4 Capacity & Lease Design

Work in progress. The v0.0.4 target is deterministic runtime enforcement of runner `max_parallelism`, single-canonical physical occupancy per logical Session, explicit release after terminal physical outcome or Session revocation, and retry admission only after predecessor capacity release.

No wall-clock lease expiry is part of the core protocol. Capacity recovery must be represented by explicit deterministic transitions.

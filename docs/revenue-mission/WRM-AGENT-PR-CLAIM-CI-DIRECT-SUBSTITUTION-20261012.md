## Question
Could a read-only zero-migration agent-PR claim checker or stalled-PR/CI recovery memo be a defensible paying product? This is a follow-on to the already weakened Agent PR Recovery Digest, not new product scope.

## Independent evidence, with limits
The 2026 research study *Analyzing Message-Code Inconsistency in AI Coding Agent-Authored Pull Requests* examined 23,247 agentic PRs and manually annotated 974. It reports 1.7% high message-code inconsistency, with high-MCI PRs associated with lower acceptance (28.3% vs 80.0%) and longer merge time (55.8 vs 16.0 hours). Association is NOT causation; buyer-segment incidence and willingness to pay are unknown. https://arxiv.org/abs/2601.04886
A self-reported small team exercise describes three junior reviewers relying on agent-generated PR descriptions rather than inspecting diffs. This is an anecdote, not a validated buyer or audited failure rate. https://www.reddit.com/r/TechLeader/comments/1wu7u7q/our_new_hires_approve_agent_prs_without_reading/

## Direct first-party substitutes
1. Vigil explicitly verifies PR-description claims against diffs, surfaces undocumented changes, and advertises a free, read-only, zero-config GitHub tier. Directly defeats a generic no-setup PR-claim verifier claim. https://keepvigil.dev/
2. PRTruth offers no-install public PR report-only verification, PROVEN/FAILED/UNPROVEN evidence states, issue acceptance-criteria checks and observed CI fact-checking. Directly defeats generic read-only acceptance-criteria evidence summaries. https://github.com/eissasoubhi/PRTruth
3. agent-done-or-not audits completion claims against execution receipts and can rerun testable PR claims; directly weakens a generic 'agent done' proof-gate claim. https://github.com/mohamedzhioua/agent-done-or-not
4. Pullfrog advertises CI auto-fix, review loops, conflict handling and GitHub CI-log reading; weakens generic stalled PR recovery advice. https://pullfrog.com/
5. Naoru reads failed pipeline logs and diffs to suggest grounded fixes on PRs; weakens generic CI root-cause summaries. https://clouddrove.com/naoru.html
6. ProPR provides open-source multi-agent GitHub PR review and repair loops; further weakens generic multi-agent PR review/approval workflows. https://propr.dev/

These are advertised capabilities, NOT independently verified installed product parity, market adoption or actual revenue.

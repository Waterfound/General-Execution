## Commercial conclusion

Current contests are not a substitute for product discovery.

They can create income, but only when the same artifact also advances a commercially supported wedge. None of the currently active challenges supplies that missing buyer evidence. Entering would otherwise create:

- platform-specific implementation;
- account and credential setup;
- public demo/publication;
- contest-specific packaging;
- identity/payment/tax verification if successful;
- high competitive variance;
- risk of abandoning the self-serve global website objective after the event.

Kiroween remains the only material future checkpoint because the rules are not yet complete and implementation is explicitly prohibited before October 30.

## Challenge admission rule

Admit a challenge to ACTIVE only if all are true:

1. Waterfound is eligible in Brazil;
2. the official build period has begun;
3. the full rules and prize terms are published;
4. a previously selected buyer problem fits the challenge without distortion;
5. the private proof can be built with existing free tools and no new credentials;
6. the project remains useful and commercially testable if it wins nothing;
7. expected value justifies the contest-specific work;
8. no prohibited pre-start work has occurred;
9. account, registration, public demo/submission, contract, payment/KYC and tax steps remain explicit gates.

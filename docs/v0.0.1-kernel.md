# v0.0.1 Execution Kernel

## Architectural boundary

General Execution is a transport/execution substrate, not a decision authority.

A producer supplies an immutable `ExecutionSpec`. The kernel may select a compatible runner and bind a logical execution attempt. It may not infer missing domain invariants, widen scopes, approve results, integrate revisions, or grant release/consensus authority.

## Identity chain

```text
ExecutionSpec.digest
    + RunnerRegistry.digest
        -> DispatchPlan.digest
            + logical attempt
                -> ExecutionSession.session_id
                    -> ResultEnvelope.digest
```

Changing any bound input changes the downstream identity.

## Deterministic planning

Compatibility requires:

- requested mode supported by the runner;
- every required capability declared by the runner.

Compatible runners are sorted deterministically by runner ID and capability digest. Registry input ordering therefore cannot change the selected runner.

## Retry semantics

Attempts are logical and monotonic from the caller's perspective. The attempt number is part of Session identity. Revocation never rewrites an old attempt; a retry is a new Session identity.

## Result semantics

The core accepts execution completion evidence only. Domain correctness is intentionally out of scope. `completed` means the physical/logical task reports completion, not that an independent verifier considers the result correct.

## Ledger

Ledger events are deterministic and hash-chained. Wall-clock timestamps are absent from consensus identity. External systems may record observational timestamps separately without changing core replay semantics.

## v0.0.1 exit gate

The kernel is ready to freeze when:

- deterministic identity tests are green;
- registry-order invariance is green;
- incompatible capability/mode dispatch fails closed;
- stale-attempt result submission is rejected;
- revoked sessions cannot submit;
- ledger payload/reordering tamper is detected;
- package imports cleanly without non-stdlib runtime dependencies.
